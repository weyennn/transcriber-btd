# Pandora UI Direction

## Identity

Pandora is a UGM portal for a local audio transcription workspace. Pandora is the entry identity; Transcriber Audio is the service inside it. The interface should feel institutional, clear, and practical before it feels technical.

## Visual language

- Palette: official UGM Blue (`#00547C`) carries structure and primary actions. UGM Yellow (`#FFD100`) is reserved for Pandora entry, keyboard focus, and selected detail. Pale blue and white keep long transcript work readable.
- Color balance: 60% white or pale blue surfaces, 30% UGM Blue and navy structure, 10% UGM Yellow accent. Yellow never becomes a large workspace background.
- Typography: Helvetica Neue for operational UI. Georgia is reserved for Pandora, giving the portal a distinct signature without making controls ornamental.
- Composition: the portal opens Pandora. The workspace begins with the user task, then source audio, settings, status, activity, result, and history.
- Surfaces: flat white cards with blue borders. Shadow is reserved for the Pandora portal and the compact hero workflow card.
- Motif: the Pandora box is the entry gesture. The hero uses an explicit three-stage workflow, File audio, Transkripsi, Hasil, rather than a decorative waveform.
- Motion: one exit transition when Pandora opens. No looping motion.

## Dials

ENERGY 2 / RHYTHM 2 / MOTION 1

## Decision reasons

- UGM Blue creates a calm, credible working surface and provides contrast for controls and transcript progress.
- UGM Yellow remains sparse so it identifies the Pandora entrance, focus, and selected state instead of competing with content.
- The compact workflow card explains the actual path to a transkrip without inventing waveform data or consuming mobile height.
- The mobile layout stacks the workflow steps and workspace in task order, avoiding clipping and horizontal scrolling.
- Radius changes by function: portal box uses a shaped form, cards use a modest surface radius, and progress uses a track shape.
